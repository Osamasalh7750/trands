## 🌐 النشر والتشغيل عبر GitHub (GitHub Pages)

المشروع متوافق 100% مع **GitHub Pages** لأن جميع الروابط نسبية، ومكتبات الربط والسحابة تعمل عبر بروتوكول HTTPS الآمن.

### خطوات النشر على GitHub Pages:
1. ارفع مجلد المشروع إلى مستودع جديد على GitHub (Repository).
2. ادخل إلى إعدادات المستودع (**Settings**).
3. اختر من القائمة الجانبية **Pages**.
4. تحت قسم **Build and deployment**:
   - اضبط الـ **Branch** على `main` (أو `master`) والمجلد على `/ (root)`.
   - اضغط **Save**.
5. سيتم نشر الموقع وتوفير رابط فوري خاص بمتجرك (مثال: `https://yourusername.github.io/trand-perfumes/`)، وسيعمل المتجر مع قاعدة بيانات Supabase ونظام الواتساب في كافة أنحاء العالم مباشرة!
